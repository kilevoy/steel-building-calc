## Формулы массы из Excel

По workbook `EXCEL-010`:

- масса колонны: `Сводка!G63 = F63 * B9 * 1.15`;
- масса с распорками: `Сводка!I63 = G63 + шаг * 9.6 * 1.15 * H63`, где для фахверковой колонны используется шаг фахверка `B12`, иначе шаг рам `B11`.

Расчетные проверки прочности/устойчивости этим изменением не затрагиваются; закреплена только ведомственная масса, как в Excel.
## Актуализация 2026-06-03 — материал распорок

Принято: распорки колонн считать как `тр.кв.80×4`, сталь `С255Б`.

Excel anchor по массе сохраняется:

- масса колонны: `F63 * B9 * 1.15`;
- масса с распорками: `G63 + шаг * 9.6 * 1.15 * H63`.

Уточнение касается стоимости: масса самой колонны оценивается по стали выбранного профиля колонны, а масса распорок — по цене `С255Б`. Проверки прочности/устойчивости и зафиксированные Excel anchors по массе этим уточнением не меняются.
