# SCN-PURLINS-003 — прогоны, ограничение максимального шага 1200 мм

Статус: `accepted for automated parity test`.

Источник: `EXCEL-009`.

Назначение: закрепить поведение подбора прогонов при ручном ограничении максимального шага. Сценарий связан с вопросом "если поставить максимальный шаг 1200, будет ли расчет до 1200".

## Входные данные

Сценарий основан на `SCN-PURLINS-001`.

Изменения:

| Параметр | Значение |
|---|---:|
| Минимальный шаг прогонов | 500 мм |
| Максимальный шаг прогонов | 1200 мм |

## Ожидаемые выходы

| Показатель | Значение |
|---|---:|
| `autoMaxStep_mm` | 1200 |
| Выбранный профиль | Z 350х2 |
| Шаг | 1185 мм |
| Количество линий прогонов | 22 |
| Масса на здание | 12126.4 кг |
| Черная масса | 378.4 кг |
| Оцинкованная масса | 11748 кг |
| Масса с распорками | 16734.4 кг |
| Коэффициент использования | 0.9842098225 |

## Автоматический тест

Тест добавлен в `src/calc/purlin/engine.acceptance.test.ts`.

Проверяются ручное ограничение `maxStep_mm`, выбранный профиль, фактический шаг, количество линий и массы.

## Инженерный смысл

При ограничении `1200 мм` расчет не обязан брать ровно 1200 мм. Он подбирает допустимый шаг не больше заданного предела. В этом сценарии получается `1185 мм`.
