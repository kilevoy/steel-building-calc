# Навигационная заметка по module-parity-matrix

Основная матрица текущего уровня сверки расчетных модулей с Excel находится в:

`knowledge/wiki/parity/module-parity-matrix.md`

Эту страницу нужно читать перед началом раздела "Единое здание" и перед любыми изменениями расчетных модулей. Она показывает:

- какие Excel-источники уже используются как oracle;
- какие automated tests реально закрепляют совпадение;
- где проверен только один сценарий;
- какие дополнительные сценарии нужны для утверждения "1 в 1 с Excel".

Существующие страницы `README.md`, `acceptance-tests.md`, `source-map.md` и `known-differences.md` остаются действующими. Эта заметка добавлена отдельно, чтобы не переписывать старые markdown-файлы с исторической кодировкой.
