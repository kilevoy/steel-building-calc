## Актуализация 2026-06-03

Текущий технический долг после публикации количества подкрановых балок и ручного количества оконных ригелей:

- Оконные ригели: количество для сводки задаётся вручную на вкладке `Оконные ригели`; нужна будущая модель фасадов/окон, чтобы считать количество автоматически.
- Подкрановая балка: количество в сводке считается как две нитки подкранового пути по длине здания и шагу балки; нужно проверить это на КМ/Excel-сценариях для разных крановых схем.
- Колонны при кране: диагностическое количество уже исключает двойной счёт торцевого фахверка, но масса/стоимость остаются по опубликованным строкам вкладки `Колонна`; нужен подтверждённый сценарий для торцевых основных колонн.
- Балка покрытия: для двускатной кровли торцевые балки покрытия считаются по двум скатам на каждом торце; нужны дополнительные КМ-сценарии для многопролётных и односкатных схем.
- Прогоны: выбор `2ТПС` разрешён только для послойной сборки; для остальных покрытий выбор между `2ПС`, `Z` и прокатным чёрным металлом остаётся решением расчётчика.
- Стоимость остаётся справочной и временной; главным критерием развития считать корректность расчётной логики и совпадение с Excel-oracle.
