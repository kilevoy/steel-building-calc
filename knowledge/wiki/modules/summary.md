# Summary

Модуль сводки агрегирует результаты расчётных вкладок и помогает увидеть общий результат по зданию.

При изменениях проверять, что сводка не искажает расчётные данные, не скрывает предупреждения и корректно отражает временные допущения.

## Количество колонн

Диагностический блок количества колонн использует принятое решение ГИПа:

- без крана торцевые колонны считаются отдельной группой фахверка/торцевых элементов;
- с краном торцевые колонны считаются основными колоннами рам;
- при кране совпадающие торцевые позиции фахверка исключаются из диагностического итога количества, чтобы не задвоить торцевые колонны.

Это пока не пересчитывает массу и стоимость строк колонн в общей таблице: они остаются опубликованными вкладкой `Колонна`. Для переноса правила в массу/стоимость нужен отдельный подтверждённый сценарий по профилям и длинам торцевых основных колонн.
