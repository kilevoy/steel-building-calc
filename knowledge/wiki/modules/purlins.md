# Purlins

Модуль прогонов отвечает за расчёт прогонов покрытия. В коде есть разделение вариантов, включая горячекатаные и ЛСТК-прогоны, если они доступны в текущей реализации.

Осевая ветровая нагрузка для прокатной ветки в базовом сценарии `SCN-PURLINS-001` сверена с Excel `Расчет!D18` в `src/calc/purlin/rolled.acceptance.test.ts`. Это закрепляет текущую формулу для default-сценария, но не закрывает дополнительные варианты со снеговым мешком, ограждением и другими схемами кровли.

При изменениях важны acceptance tests, диагностические поля и проверка, что справочники профилей и коэффициенты не изменены случайно.

Связанный Excel-oracle candidate: `EXCEL-009`, описан в `knowledge/wiki/parity/excel-009-purlins.md`.

Инженерное правило выбора семейств:

- `2ТПС` — термопрофиль с прослойкой; его допускается подбирать только для кровли из послойной сборки `наше ...` (`наше 100 мм`, `наше 150 мм`, `наше 200 мм`, `наше 250 мм` и варианты с ГВЛ).
- Для профлиста, сэндвич-панелей и прочих кровель `2ТПС` не должен участвовать в подборе.
- В остальных случаях расчетчик должен видеть выбор между `2ПС`, `Z` и прокатным черным металлом. Автоматический расчет может показать расчетные кандидаты, но окончательный выбор между этими тремя ветками остается инженерным решением.
- Прокатные прогоны считаются отдельной веткой черного металла; шаг прокатных прогонов в текущей реализации фиксирован 1500 мм.

При будущей сверке отдельно проверять дополнительные прокатные/горячекатаные варианты и ЛСТК МП350/МП390. Методика axial wind load для `SCN-PURLINS-001` подтверждена acceptance-сценарием; новые сценарии не должны менять её expected values без явного Excel-oracle источника.
