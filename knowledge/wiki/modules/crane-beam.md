# Crane Beam

Модуль подкрановой балки связан с тяжёлыми workbook/generated-данными и должен загружаться лениво.

Важно сохранить dynamic import расчётного engine, чтобы workbook generated-файлы не попадали в стартовый chunk. При изменениях проверять build output и отсутствие статического импорта тяжёлого engine.

Связанный Excel-oracle: `EXCEL-006`, описан в `knowledge/wiki/parity/excel-006-crane-beam.md`.

При будущей сверке проверять входы по крану, рельсу, пролёту ПБ, тормозной конструкции, расчётные усилия, прочность, устойчивость, усталость и прогибы. Lazy loading этого модуля является архитектурным требованием.

## Производительность (2026-06-12)

Книга HyperFormula кэшируется в `engine.ts` на уровне модуля; входные ячейки перезаписываются батчем при каждом расчёте. Это не меняет формулы и закреплено тестом изоляции кэша в `engine.acceptance.test.ts`. `CraneBeamRunnerProvider` прогревает workbook-чанк в фоне при `building.hasCrane = true`. Dynamic import сохранён — чанк по-прежнему не попадает в стартовый bundle.

Автоматическая parity-сверка:

- `SCN-CRANE-BEAM-001`: default 5 т;
- `SCN-CRANE-BEAM-002`: 10 т;
- `SCN-CRANE-BEAM-003`: два крана 10 т.

Тесты проверяют профиль, utilization, массу, прогиб, lookup-значения крана и заполнение блоков геометрии, прочности, общей/местной устойчивости, усталости и прогибов.

## UI-покрытие входов

В UI сейчас доступны основные входы workbook:

- кран: грузоподъёмность, пролёт крана, число колёс одной стороны, тип подвеса, группа режима работы, число кранов, рельс;
- балка: пролёт балки, тормозная конструкция, шаг рёбер, расчёт на усталость;
- коэффициенты: `γf`, `γd`, `γc`, `kсв`;
- цены берутся из общего блока `PricesBlock`.

Открытые вопросы:

- подтвердить, какой шаг рёбер использовать как пользовательски значимый результат: исходный `B19` или подобранный `D19`;
- проверить связь крановых полей с модулем колонны и автопередачей нагрузок;
- проверить количество подкрановых балок в Summary на КМ/Excel-сценариях для разных схем кранов.

Lazy loading этого модуля является архитектурным требованием.
